# Телефонная книга — просмотр всех записей (C#)

Консольная программа на C#/.NET 10, которая выводит **все записи телефонной книги**
в виде аккуратной таблицы: имя, телефон, категория и примечание, плюс итог по количеству
записей и разбивку по категориям.

## Требования

* .NET SDK 10.0 или новее (`dotnet --version`).
* Windows / Linux / macOS — программа кроссплатформенная.

## Запуск

```powershell
cd C:\Programming\TestAI\Deepseek_Harness
dotnet run
```

Или собранным exe:

```powershell
dotnet build -c Release
.\bin\Release\net10.0\PhoneBookViewer.exe
```

### Параметры командной строки

| Параметр | Назначение |
| --- | --- |
| `-f, --file <путь>` | JSON-файл с телефонной книгой (по умолчанию `data/phonebook.json`) |
| `-s, --sort <поле>` | сортировка перед выводом: `name` (по имени) или `category` (по категории) |
| `-h, --help`, `-?` | справка |
| `-v, --version` | версия программы |

Примеры:

```powershell
PhoneBookViewer
PhoneBookViewer --file C:\data\contacts.json
PhoneBookViewer --sort name
```

## Формат файла данных

`data/phonebook.json` — простой массив объектов:

```json
[
  {
    "name": "Анна Иванова",
    "phone": "+7 916 123-45-67",
    "category": "Семья",
    "note": "Домашний номер"
  }
]
```

* `name`, `phone` — обязательные поля;
* `category` — необязательное, по умолчанию «Без категории»;
* `note` — необязательное примечание (длинные примечания обрезаются при выводе).

Если файл не найден, программа **создаёт** его с образцом из 8 записей и сразу показывает.
Пустой массив (`[]`) или пустой файл — выводится сообщение «Телефонная книга пуста».

## Обработка ошибок

| Ситуация | Поведение | Код возврата |
| --- | --- | --- |
| Всё в порядке | таблица записей | `0` |
| Файл не найден | создаётся образец и выводится | `0` |
| Файл повреждён (невалидный JSON) | сообщение об ошибке в stderr | `1` |
| Нет прав / ошибка ввода-вывода | сообщение об ошибке в stderr | `1` |
| Неизвестный параметр | сообщение об ошибке в stderr | `2` |

## Примечания

* Вывод в UTF-8, кириллица и псевдографика отображаются корректно в Windows Terminal,
  PowerShell 7 и современных консолях.
* Программа только читает данные — ничего не изменяет в телефонной книге.
